7.1 — RISC-V Processor Design Project ⭐ Flagship Portfolio Piece

Fig 7.1 — The classic 5-stage pipeline. Data hazards are solved with forwarding paths (bypass EX/MEM results back into EX before they're written to the register file); control hazards (branches) are solved with prediction + pipeline flush.

Project plan (4 weeks)

WeekGoal
1Study RV32I ISA (47 instructions). Build single-cycle datapath: ALU, 32×32-bit register file, immediate generator, PC logic
2Control unit (FSM or ROM-based), instruction decode, instruction/data memory interface
3Add pipeline registers (IF/ID, ID/EX, EX/MEM, MEM/WB), forwarding unit, branch flush logic
4Run RISC-V compliance tests, synthesize with Yosys, run full physical design in OpenROAD to get a real GDSII
Reference: Patterson & Hennessy — Computer Organization and Design (RISC-V Edition) is the must-read here. Also check riscv.org/specifications and github.com/riscv/riscv-compliance for the test suite, and picorv32 as a reference implementation.

7.2 — AES Encryption Core Project

Implement AES-128 in Verilog: RTL → functional verification → synthesis → power analysis. Optimize for throughput (pipeline), area (iterative datapath reuse), or power (clock gating) depending on what you want to showcase. This demonstrates security-hardware knowledge, which is valued highly at Intel, Qualcomm, and Arm.

7.3 — OpenROAD Chip Tapeout

Take your RISC-V or AES core through the complete physical design flow using OpenROAD, targeting Sky130 or Nangate45. Aim to actually submit to the Efabless Open MPW shuttle. Document your floorplan, placement density, routing congestion, and the story of how you closed timing — this is exactly what interviewers want to hear about.

50 must-know interview questions

MOSFET & CMOS (1–15)

  1. Draw nMOS and pMOS cross-sections. Key differences?
  2. Explain the three MOSFET operating regions with equations.
  3. What is threshold voltage? How does body effect change it?
  4. What is channel length modulation? Which parameter models it?
  5. Why does subthreshold leakage increase with technology scaling?
  6. Draw a CMOS inverter and explain operation for both input states.
  7. Draw the VTC of a CMOS inverter — label all 5 regions and VM.
  8. Calculate propagation delay of an inverter driving a 50fF load.
  9. What are noise margins? How do you calculate NMH and NML?
  10. Why is NAND preferred over NOR in CMOS?
  11. Design a CMOS implementation of Y = A·B + C with minimum transistors.
  12. What is a transmission gate? Where is it used?
  13. Difference between static and dynamic CMOS?
  14. What is charge sharing in dynamic CMOS? How is it prevented?
  15. Compare power dissipation: static CMOS vs. pseudo-nMOS vs. dynamic CMOS.

Verilog & RTL (16–30)

  1. Difference between blocking and non-blocking assignment?
  2. Write Verilog for a D flip-flop with async reset.
  3. Write Verilog for a 4:1 MUX.
  4. What is a latch? When does Verilog infer one, and is that good or bad?
  5. Difference between always @(*) and always @(posedge clk)?
  6. Difference between wire and reg?
  7. Write a Moore FSM for a sequence detector (detect "1010").
  8. Difference between Moore and Mealy FSMs?
  9. Write Verilog for a parameterized N-bit shift register.
  10. What does $random do, and when would you use it in a testbench?
  11. What is a race condition in Verilog? Give an example.
  12. What does `timescale 1ns/1ps mean?
  13. What is logical equivalence checking (LEC)?
  14. What is RTL lint? Name 3 things a lint tool checks.
  15. Describe the synthesis flow from RTL to gate-level netlist.

Physical Design & STA (31–40)

  1. What are the steps in a physical design flow?
  2. What is floorplanning? What decisions get made there?
  3. What is IR drop? Why does it matter, and how is it fixed?
  4. What is clock skew? How does it affect setup vs. hold timing?
  5. What is clock tree synthesis, and what does it achieve?
  6. What is a setup time violation? How is it fixed?
  7. What is a hold time violation? Can it be fixed by reducing frequency?
  8. What is crosstalk? Differentiate crosstalk noise vs. crosstalk delay.
  9. What is electromigration, and how does it affect metal layer design?
  10. What are process corners? Which is worst for setup vs. hold?

DFT (41–45)

  1. What is scan design? Explain how a scan flip-flop works.
  2. What is fault coverage? What's a typical target percentage?
  3. What is ATPG? Name two ATPG algorithms.
  4. What is JTAG/boundary scan, and why is it used?
  5. What is LBIST? What are PRPG and MISR?

Fabrication (46–50)

  1. Explain the CMOS twin-well process in 10 steps.
  2. What is STI, and why did it replace LOCOS?
  3. Difference between CVD and PVD — when is each used?
  4. What is ion implantation, and why is it preferred over thermal diffusion?
  5. What is EUV lithography, and why was it needed?
