1.1 — Semiconductor Physics Refresh NPTEL

Energy bands & carriers

In a crystal, allowed electron energies group into bands separated by a bandgap (Eg). Conduction requires electrons in the conduction band, or holes (missing electrons) in the valence band.

Fig 1.1 — Band diagrams for conductor, semiconductor, and insulator. Silicon's small bandgap (1.12 eV) is why doping and temperature both strongly affect its conductivity — the basis of every semiconductor device.

Key numbers to memorize

Silicon bandgap Eg = 1.12 eV @ 300K Thermal voltage VT = kT/q ≈ 26 mV @ 300K Intrinsic carrier conc. ni ≈ 1.5 × 10¹⁰ cm⁻³ ni = √(Nc·Nv) · exp(−Eg / 2kT)

p-n Junction

When p-type and n-type regions meet, carriers diffuse across the junction and recombine, leaving behind fixed charge (ionized dopants) — this forms the depletion region and a built-in electric field that opposes further diffusion.

Fig 1.2 — p-n junction at equilibrium. Fixed ionized dopants (⊖ in p-side, ⊕ in n-side) create the built-in field that balances diffusion. Forward bias narrows this region; reverse bias widens it.
Diode equation: I = I₀ · (e^(V / n·VT) − 1) Junction capacitance Cj ∝ 1/√(Vbi − V) — matters for VLSI timing (diffusion caps)
Lab: Solve 10–15 numericals on Vbi, depletion width, and Cj using Neamen's exercise sets. Draw band diagrams for p-type, n-type, and the junction under forward/reverse bias.

BJT — brief context only

NPN/PNP, active/saturation/cutoff, current gain β. You only need enough to understand why ICs moved from BJT to MOSFET: MOSFETs are voltage-controlled (near-zero static gate current), scale better, and dissipate far less power per gate — which is why CMOS, not bipolar logic, became the basis of digital ICs.

1.2 — MOSFET: The Heart of VLSI NPTEL Core

Structure

Fig 1.3 — nMOS structure: p-type substrate, n+ source/drain, poly-Si gate over thin gate oxide. When VGS exceeds Vth, an inversion layer (n-channel) forms under the gate, connecting source to drain. pMOS is the dual: n-well substrate, p+ source/drain.

Threshold voltage & body effect

Vth = VFB + 2φF + √(2·εsi·q·NA·2φF) / Cox Body effect (back-gate effect): Vth(VSB) = Vth0 + γ·(√(2φF + VSB) − √(2φF))

γ = body-effect coefficient. This matters directly in stacked CMOS circuits (e.g. series NAND transistors) where the internal transistor's source isn't at ground — its effective Vth rises.

Operating regions

RegionConditionID equation
CutoffVGS < VthID ≈ 0
Linear / TriodeVGS > Vth, VDS < VGS−VthID = μnCox(W/L)[(VGS−Vth)VDS − VDS²/2]
SaturationVGS > Vth, VDS ≥ VGS−VthID = (μnCox/2)(W/L)(VGS−Vth)²
Fig 1.4 — ID–VDS family of curves. Left of the dashed boundary = triode (resistive); right = saturation (current source, roughly flat — slope is channel length modulation λ). Higher VGS shifts the whole curve up.

Key derived parameters

Transconductance: gm = ∂ID/∂VGS = μnCox(W/L)(VGS−Vth) [saturation] Output conductance: gds = ∂ID/∂VDS (channel length modulation λ) Intrinsic gain: Av = −gm/gds Cutoff frequency: fT = gm / (2π(Cgs+Cgd))

Short-channel effects (why modern transistors misbehave)

EffectWhat happens
Channel Length ModulationEffective channel shortens with VDS → ID rises slightly in saturation (λ term)
Velocity SaturationCarrier velocity caps out at high fields → ID grows linearly with VGS, not quadratically
DIBLDrain field lowers the source barrier → Vth drops as VDS increases
Subthreshold leakageID doesn't truly reach 0 below Vth; subthreshold slope S ≈ 60 mV/decade ideal
Hot Carrier InjectionHigh-energy carriers get trapped in gate oxide → long-term Vth drift/degradation

All of these worsen as technology nodes shrink (90nm → 45nm → 7nm), which is exactly why leakage power now rivals switching power in modern chips (see Phase 6, Low Power Design).

Lab (LTSpice, free):
  • Plot ID–VDS curves for nMOS at several VGS values
  • Plot ID–VGS curve; extract Vth, gm, subthreshold slope
  • Compare a simple LEVEL 1 model vs. BSIM4 — observe short-channel effects appear only in BSIM4
  • Calculate required W/L for a target current drive
NPTEL-style practice:
  1. nMOS: μnCox = 200 μA/V², W/L = 10, Vth = 0.5V. Find ID at VGS=1.8V, VDS=1.8V.
  2. Why does scaling down channel length increase subthreshold leakage?
  3. Calculate fT for gm = 2 mA/V, Cgs = 20 fF, Cgd = 5 fF.

1.3 — CMOS Inverter NPTEL Core

Fig 1.5 — When Vin = LOW → pMOS ON, nMOS OFF → Vout pulled to VDD. When Vin = HIGH → pMOS OFF, nMOS ON → Vout pulled to GND. No DC path VDD→GND ever exists in steady state → zero static power (in the ideal case, ignoring leakage).

Voltage Transfer Characteristic (VTC)

Fig 1.6 — VTC has 5 regions (A–E). VM = switching threshold, where Vin=Vout and both transistors are in saturation (region C). Gain in the transition region must exceed 1 in magnitude for regenerative digital logic.
Sizing for symmetric switching: (W/L)p / (W/L)n = μn/μp ≈ 2–3 (pMOS made ~2× wider — hole mobility is lower) Noise margins: NMH = VOH − VIH NML = VIL − VOL Propagation delay: tpHL = 0.69·Rn·CL tpLH = 0.69·Rp·CL tp = (tpHL+tpLH)/2 Power: Pdyn = α·CL·VDD²·f Pstat = Ileakage·VDD Ptotal = Pdyn + Pstat + Psc
Lab (LTSpice + FreePDK45/180nm PDK):
  • Simulate CMOS inverter VTC, extract VOH, VOL, VIH, VIL, NMH, NML
  • Measure tpHL, tpLH across different CL values
  • Plot power vs. frequency

1.4 — CMOS Logic Gates NPTEL Core

Complementary CMOS structure

Pull-Down Network (PDN, nMOS) implements the function directly; Pull-Up Network (PUN, pMOS) is its dual. Rule: series nMOS ↔ parallel pMOS, and parallel nMOS ↔ series pMOS.

Fig 1.7 — NAND2 (left): pMOS parallel + nMOS series. NOR2 (right): pMOS series + nMOS parallel. Series pMOS = higher resistance (pMOS mobility already lower) → NOR is slower than NAND. This is why NAND is the preferred building block in CMOS — a favorite NPTEL question.

Complex (AOI/OAI)mixed series-parallel, dual networks

Transmission gate

nMOS + pMOS in parallel, gates driven by complementary signals (S and S̄). Passes both strong-0 and strong-1 without the Vth drop a lone nMOS pass transistor suffers. Core building block for MUXes, XOR gates, and latches.

Logical effort (industry-important sizing method)

Logical effort g: inverter g=1, NAND2 g=4/3, NOR2 g=5/3 Path effort: F = G·B·H (G = product of g's, B = branching, H = electrical/fanout effort) Optimal stage effort: ĝ ≈ 4 (rule of thumb range 3–5)

Dynamic CMOS (brief)

Precharge (CLK=0) then evaluate (CLK=1) phases — fewer transistors, faster, but prone to charge sharing (internal nodes steal charge from the output during evaluate) and floating-node issues. Domino logic fixes the non-inverting output problem by adding a static inverter after each dynamic gate.

NPTEL-style practice:
  1. Design CMOS realization of Y = AB + CD with minimum transistors.
  2. Calculate logical effort of a 3-input NAND gate.
  3. Why is charge sharing a problem in dynamic CMOS, and how is it fixed?
  4. Compare static vs. dynamic CMOS on power, speed, complexity.
Lab:
  • Design & simulate 2-input NAND, NOR, XOR in static CMOS (LTSpice)
  • Implement a full adder using static CMOS (28 transistors)
  • Compare delay: NAND-based vs. NOR-based implementation of the same function
  • Design a 2:1 MUX using transmission gates
