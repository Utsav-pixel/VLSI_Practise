2.1 — MOS Memory Circuits

6T SRAM cell

Fig 2.1 — Two cross-coupled inverters (4 transistors) store Q/Q̄; two nMOS access transistors (M5, M6) connect the cell to bitlines BL/BL̄ when the wordline is asserted. Stability is measured via the Static Noise Margin (SNM), found from the "butterfly curve" — a common NPTEL diagram-based question.
Read SNM vs. Write SNM: opposing requirements Cell ratio (CR) = (W/L)driver / (W/L)access → affects Read stability Pull-up ratio (PR) = (W/L)load / (W/L)access → affects Write ability

DRAM — 1T-1C cell

Single access transistor + storage capacitor. Read is destructive (charge redistributes onto the bitline) so data must be rewritten after every read, and cells need periodic refresh (~every 64 ms) because the capacitor leaks. Much denser than SRAM but slower — hence SRAM for caches/registers, DRAM for main memory.

Flash & ROM (awareness level)

Flash: floating-gate transistor, programmed via hot-carrier injection or Fowler-Nordheim tunneling. NOR flash (fast random read, byte-addressable) vs. NAND flash (denser, block-addressable, used in SSDs). ROM types: Mask ROM, PROM, EPROM, EEPROM — differ in how/whether they can be reprogrammed.

2.2 — Sequential Logic Circuits in CMOS NPTEL Core

D Flip-Flop (master-slave)

Fig 2.2 — Master latch is transparent while CLK=0 (captures D); when CLK rises, master closes and slave opens, passing the captured value to Q. This series combination is what gives a true edge-triggered flip-flop from two simple transmission-gate latches.
Timing constraint: T_clk > tCQ + t_comb + t_setup Setup time (tsetup), Hold time (thold), Clock-to-Q (tCQ) Metastability: if setup/hold violated, output can hang in an undefined state — quantified by MTBF (Mean Time Between Failures)
Lab: Simulate a D flip-flop in LTSpice, measure tsetup, thold, tCQ directly from waveforms. Build a 4-bit shift register from D-FFs and verify serial in/out operation.

2.3 — Arithmetic Circuits Industry Core

Adders

Adder typeDelayNotes
Ripple Carry Adder (RCA)O(n) — delay = n × tFASimplest, but slow for wide words
Carry Lookahead Adder (CLA)fasterUses Generate (G) & Propagate (P) signals to compute carries ahead of time
Carry Select Adderfaster stillComputes both carry-in=0 and carry-in=1 results in parallel, muxes the right one
Kogge-Stone AdderO(log n)Parallel prefix adder — used in modern high-speed processors
Fig 2.3 — RCA's carry chain ripples through every full adder — critical path grows linearly with word width. CLA precomputes carries from Generate (Gi = Ai·Bi) and Propagate (Pi = Ai⊕Bi) signals in a separate block, breaking the serial dependency.

Multipliers

Array multiplier: grid of AND gates + adders forming partial products, summed via a carry-save array. Booth encoding: reduces the number of partial products by roughly 2× by examining bit pairs/triples. Wallace tree: reduces partial products in parallel using carry-save adders, achieving O(log n) reduction depth. MAC (multiply-accumulate) units built from these are the workhorse of DSP chips and neural network accelerators.

Lab:
  • Implement 4-bit RCA in Verilog, verify with a testbench
  • Implement 4-bit CLA in Verilog, compare critical path delay vs. RCA
  • Synthesize both in Yosys (free), compare area and timing reports

2.4 — Interconnects, Wires & Signal Integrity

Fig 2.4 — A wire is modeled as a ladder of lumped R and C segments. Elmore delay: tD = Σᵢ(Rᵢ × Cdownstream,i) — each resistor's delay contribution is weighted by all capacitance it must charge downstream. This is why long global wires dominate delay in modern chips even though gate delays keep shrinking.
Wire resistance: R = ρL / (W×H) Sheet resistance: Rs = ρ/H [Ω/□]

Signal integrity concerns

IssueCauseMitigation
Crosstalk noiseCapacitive coupling between adjacent wiresShielding, spacing, layer assignment
Crosstalk delaySame coupling causes timing shift, not logic failureSame as above; account for in STA
ElectromigrationMetal atoms migrate under high current densityKeep current density below Jmax by sizing wires
IR dropVoltage drop across resistive power grid under loadWider power straps, more grid density, decap placement

Interconnect scaling note: RC delay actually increases as technology scales down, even as gate delay shrinks — this is why copper (lower resistivity than aluminum) and low-k dielectrics became necessary around the 1997 130nm node transition.
